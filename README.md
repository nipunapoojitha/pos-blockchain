# pos-blockchain
A next-gen Proof of Stake (PoS) blockchain &amp; DeFi ecosystem built from scratch in pure Node.js . Features a decentralized P2P network, zero-inflation tokenomics , a Turing-complete Smart Contract VM, an AMM DEX, NFT engine, cross-chain bridge, and sleek Web3 UI dashboards . Secured by secp256k1 ECDSA cryptography.
